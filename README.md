# TubeKids

ספריית סרטונים מקומית ופשוטה לילדים. הסרטונים נקראים מתיקייה במחשב ואינם נטענים מ־URL או מ־YouTube.

## שימוש

1. העתיקו קובצי וידאו אל התיקייה `C:\Users\or.h\Videos`. נתמכים MP4, WebM, OGV, MOV ו־M4V.
2. אפשר ליצור בתוכה תיקיות משנה; שם תיקיית המשנה העליונה ישמש אוטומטית כקטגוריה.
3. לחצו פעמיים על `TubeKids.cmd`.

היישום סורק את התיקייה בכל הפעלה. כדי לקלוט קבצים שנוספו כשהיישום כבר פתוח, היכנסו למצב הורים ולחצו על **רענון מהתיקייה**. קוד ברירת המחדל למצב הורים הוא `1234`.

מועדפים, סטטוס צפייה ותגיות נשמרים מקומית בדפדפן. קובצי הווידאו עצמם אינם משתנים.

## בחירת תיקייה אחרת

ברירת המחדל מוגדרת בשורה זו בתחילת `start-tubekids.ps1`:

```powershell
$videoFolder = 'C:\Users\or.h\Videos'
```

כדי למשוך סרטונים מתיקייה קבועה אחרת, החליפו אותה בנתיב מלא, לדוגמה:

```powershell
$videoFolder = Join-Path $projectRoot 'videos'
```

מומלץ להשתמש בקובצי MP4 בקידוד H.264/AAC לתאימות הטובה ביותר עם Chrome ו־Edge.
