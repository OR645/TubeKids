# TubeKids

**ספריית סרטונים מקומית, בטוחה ופשוטה — לילדים.**

הסרטונים נטענים מתיקייה במחשב. אין YouTube, אין פרסומות, אין אינטרנט.

</div>

---

## התחלה מהירה

1. העתיקו קובצי וידאו אל `%USERPROFILE%\Videos\TubeKids` (נוצרת אוטומטית בהפעלה הראשונה)
2. לחצו פעמיים על **`TubeKids.cmd`**
3. זה הכל 🎬

פורמטים נתמכים: `MP4` · `WebM` · `OGV` · `MOV` · `M4V`
מומלץ MP4 בקידוד H.264/AAC לתאימות מלאה עם Chrome ו־Edge.

## תכונות

| | |
|---|---|
| 📁 **קטגוריות אוטומטיות** | שם תיקיית המשנה הופך לקטגוריה |
| ⭐ **מועדפים ותגיות** | נשמרים מקומית בדפדפן |
| 🔍 **חיפוש חי** | סינון לפי שם, קטגוריה או תגית |

| 🔒 **מצב הורים** | עריכת פרטי סרטון ורענון הספרייה |

## מצב הורים

קוד ברירת המחדל: **`1234`** (ניתן לשינוי ב־`app.js`).

הספרייה נסרקת בכל הפעלה. כדי לקלוט קבצים שנוספו בזמן שהיישום פתוח — היכנסו למצב הורים ולחצו **רענון מהתיקייה**.

## שינוי תיקיית הסרטונים

ברירת המחדל היא `Videos\TubeKids` של המשתמש המחובר — כולל הפניה ל־OneDrive או לכונן אחר. אין מה לערוך.

לתיקייה אחרת, בלי לגעת בקוד:

```powershell
# חד־פעמי
.\start-tubekids.ps1 -VideoFolder 'D:\Kids'

# קבוע
setx TUBEKIDS_VIDEO_FOLDER "D:\Kids"
```

## מבנה הפרויקט

```
TubeKids.cmd          הפעלה בקליק כפול
start-tubekids.ps1    שרת מקומי + סריקת תיקיית הווידאו
index.html            ממשק היישום
app.js                לוגיקה, נגן ומצב הורים
styles.css            עיצוב
data/videos.json      אינדקס הסרטונים (נוצר אוטומטית)
```
